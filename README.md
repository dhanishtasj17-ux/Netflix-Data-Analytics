# Netflix Data Analysis Project

## 📌 Overview
This project analyzes Netflix movies and TV shows using Python and Power BI.

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Power BI
- CSV Dataset

## 📊 Project Includes
- Data cleaning using Python
- Exploratory data analysis
- Visualizations using Python
- Interactive Power BI dashboard
- Netflix movies and TV shows analysis

## 📁 Files
- `netflix_analysis.ipynb` – Python data analysis
- `netflix_titles.csv` – Original Netflix dataset
- `netflix_titles_cleaned.csv` – Cleaned dataset
- `Netflix_Data_Analysis_Dashboard.pbix` – Power BI dashboard

## 🎯 Objective
To explore Netflix content and identify trends based on factors such as release year, content type, genres, countries, and other available attributes.
